# Basedash Cursor Plugin

A [Cursor](https://cursor.com) plugin for asking questions of governed company data and discovering connected data sources through Basedash.

## Installation

1. Open Cursor settings
2. Navigate to **Plugins**
3. Click **Browse Marketplace**
4. Search for "Basedash"
5. Click **Install**

The first connection opens a browser window to sign in to your Basedash account with OAuth. The plugin requires no API key, and your Basedash workspace access controls continue to apply.

## What it does

- Ask Basedash's AI data analyst about metrics, trends, lookups, and deeper analysis
- List the databases, warehouses, and SaaS sources connected to your workspace
- Continue a data conversation using its existing Basedash chat
